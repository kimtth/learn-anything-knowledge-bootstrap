구조([Wikipedia](https://en.wikipedia.org/wiki/Architecture))는 기계가 어떻게 조직되는지를 다루며, 소프트웨어는 그 하드웨어를 유용한 시스템으로 바꾼다. 이론적 측면은 무엇을 계산할 수 있는지와 얼마나 효율적으로 계산할 수 있는지를 묻는다.

디지털 컴퓨터는 일반적으로 제어 장치, 산술 논리 장치, 메모리, 입출력 장치를 포함하며, 프로세서는 명령과 데이터를 조정한다.

알고리즘과 자료 구조는 핵심적인 지적 도구이다. 알고리즘은 문제 해결을 위한 단계별 절차를 설명하고, 자료 구조는 그러한 절차가 효율적으로 작동하도록 정보를 조직한다. 이들의 분석은 정확성, 시간, 메모리, 확장성을 고려한다.

이는 추상화를 이 분야의 중심으로 만든다. 프로그램은 소스 코드, 기계 명령, 수학적 절차, 데이터 변환 또는 사용자 및 하드웨어와의 상호작용으로 연구할 수 있다. 컴퓨터 과학은 시스템을 설계하고, 증명하고, 최적화하고, 디버그하고, 유지할 수 있도록 이 수준들 사이를 오간다.

소프트웨어 시스템에는 컴파일러, 운영 체제, 데이터베이스, 네트워크, 그래픽스, 사용자 인터페이스가 포함된다. 각 영역에는 언어 번역, 프로세스 스케줄링, 메모리 관리, 기록 저장, 데이터 보호, 이미지 표시, 사람이 기계와 상호작용하도록 하는 일이라는 고유한 공학 문제가 있다.

컴퓨터 과학자는 물리적 생산이나 배포 전에 칩, 평면도, 소프트웨어를 설계하는 데 도움이 되는 CAD 도구와 형식 기법도 구축한다.

## 발전

컴퓨터 과학([Wikipedia](https://en.wikipedia.org/wiki/Computer_science))은 전기 공학과 수학에 뿌리를 두고 20세기 중반 디지털 컴퓨터의 등장 및 전문 소프트웨어와 네트워크 시스템의 성장으로 발전했다. 분야는 고립된 계산기에서 복잡한 범용 정보 시스템으로 옮겨 갔다.

이 분야의 발전은 프로그래밍 가능한 기계의 등장, 이어서 컴파일러, 운영 체제, 데이터베이스, 통신망의 출현을 따랐다. 컴퓨터 과학은 전기 공학과 수학에 뿌리를 두고 약 1960년에야 독립된 학문으로 등장했다. “인공 지능”이라는 용어는 1956년에 만들어졌고, 컴퓨터 그래픽스는 1950년대 초에 나타났으며, 자기 디스크 저장 장치의 발명은 1960~70년대에 데이터베이스와 현대적 데이터베이스 관리 시스템으로 이어졌다. 각 단계는 컴퓨터가 할 수 있는 일을 넓히고 이론과 설계의 필요를 심화했다.

계산 이론은 또 하나의 기둥이다. 계산 가능성, 오토마타, 형식 언어, 복잡성에 관한 질문은 어떤 문제는 효율적으로 풀 수 있고, 어떤 문제는 큰 비용을 들여야 하며, 어떤 문제는 전혀 풀 수 없음을 보여 준다. 이러한 이론적 측면은 컴퓨터 과학을 수학 및 논리학과 연결한다.

인공 지능, 수치 해석, 시뮬레이션, 그래픽스는 이 분야의 응용 측면을 보여 준다. 이들은 계산을 이용해 추론을 모델링하고, 과학 문제를 풀며, 이미지를 표현하고, 작업을 자동화한다. 따라서 컴퓨터 과학은 추상화와 구현 사이를 끊임없이 오간다.

프로그래밍 언어는 주요 분야이다. 언어는 인간의 가독성과 기계 실행 사이의 균형을 맞춰야 하며, 그 설계에는 구문, 의미론, 타입 지정, 제어 구조, 데이터 추상화, 인터프리터나 컴파일러에 의한 번역이 포함된다. 이 진화는 초기 FORTRAN(Formula Translator)과 업무 지향 COBOL에서, 다트머스의 존 케메니와 토머스 커츠가 만든 BASIC 같은 교육용 언어, 파스칼과 C 같은 명령형 후속 언어, 인공 지능에 선호된 LISP 같은 함수형 언어, Prolog 같은 선언형 논리 언어, 1983년부터 1997년까지 미국 국방부 표준이었던 Ada 같은 동시성 언어로 이어진다.

운영 체제는 프로세서, 메모리, 저장 장치, 파일, 장치, 사용자를 관리한다. 많은 작업을 조정하고 프로그램이 서로 간섭하지 않도록 보호함으로써 하드웨어를 사용할 수 있게 한다. 데이터베이스도 마찬가지로 대량의 정보를 조직하여 데이터를 저장, 검색, 갱신, 보호할 수 있게 한다.

컴퓨터 네트워크는 또 다른 층을 더한다. 네트워크에는 프로토콜, 주소 지정, 라우팅, 오류 제어, 보안이 필요하다. 현대 컴퓨터 과학은 고립된 기계보다 분산 시스템을 점점 더 연구한다.

이 분야는 신뢰성 문제를 중심으로도 발전했다. 컴퓨터가 기업, 정부, 교통, 의학, 통신에 들어가면서 오류는 비용이 커졌다. 복잡한 시스템을 믿을 수 있게 만들기 위해 소프트웨어 공학, 검증, 시험, 결함 허용, 보안 설계가 등장했다.

실시간 시스템은 더 엄격한 요구 사항을 더한다. 센서 데이터, 계산, 제어 출력은 자동차, 항공기, 공장 또는 다른 제어 과정에서 마감 기한을 충족할 만큼 빠르게 이루어져야 한다.

병렬 및 분산 컴퓨팅은 단일 프로세서가 모든 대규모 문제를 효율적으로 풀 수 없었기 때문에 중요해졌다. 슈퍼컴퓨터, 다중 프로세서, 네트워크 시스템은 작업을 많은 구성 요소에 나누지만, 이는 동기화, 통신, 성능이라는 새로운 문제를 만든다.

유용한 시스템은 사람이 이해하고 제어할 수 있어야 하므로 인간-컴퓨터 상호작용도 이 분야의 일부이다. 인터페이스, 그래픽스, 입력 장치, 사용성은 기술 설계를 인간의 지각, 작업 습관, 소통과 연결한다.

이는 컴퓨터 과학을 형식 시스템과 실용적인 인간 사용을 모두 다루는 학문으로 만든다.

## 핵심 방정식

컴퓨터 과학은 일반적으로 점근 표기와 이진 표기를 사용해 알고리즘과 정보를 측정한다.

$$T(n)=O(n\log n)$$

빅오 표기법은 실행 시간이 입력 크기에 따라 어떻게 증가하는지 설명하며, 여기서는 효율적인 분할·결합 알고리즘에 전형적인 비율을 나타낸다.

$$\text{bits}=\log_2 N$$

이는 동일하게 가능한 $N$개의 상태를 구별하는 데 필요한 이진 선택의 수를 표현한다.
