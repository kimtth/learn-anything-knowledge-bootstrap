# Memory

> [!abstract] Reference navigation
> Memory is the encoding, storage, and retrieval of experience, allowing past events and acquired skills to guide later perception, learning, reasoning, and behavior. Its study distinguishes sensory, short-term, working, and long-term memory while examining rehearsal, interference, forgetting, amnesia, and aging.

## Introduction

![[attachments/memory_001.png|420]]

*Working memory model*

Memory ([Wikipedia](https://en.wikipedia.org/wiki/Memory)) is the encoding, storage, and retrieval of past experience in the human mind. Remembering shows that experience can influence later behavior, perception, attention, and learning. Skills such as music performance, poem recitation, reading, problem solving, and reasoning all depend on memory because events must be represented in the brain and later used.

Memory is often described through sensory memory ([Wikipedia](https://en.wikipedia.org/wiki/Sensory_memory)), short-term memory, long-term memory, and working memory. Sensory memory briefly holds visual, auditory, or other impressions. Short-term memory holds a small amount of information for a short time, while long-term memory stores larger bodies of knowledge, skills, and experiences.

## Working Memory

Working memory ([Wikipedia](https://en.wikipedia.org/wiki/Working_memory)) supports complex thinking by combining short-term storage with executive attention. Alan Baddeley compared it to a scratch pad where needed information is kept briefly and then replaced. Executive attention blocks distractions, selects what enters short-term memory, and helps active information guide reasoning or task performance.

## Intervals

![[attachments/memory_002.webp|420]]

*Ebbinghaus forgetting curve*

Spacing practice improves long-term retention. A learner who studies one hour per day for five days may remember better after a week than someone who studies five hours in one day, even though total practice time is equal. Memory improves when attention returns to information across intervals rather than only in one concentrated session.

## Rehearsal

Rehearsal helps memory, but different forms work differently. Rote repetition can keep information active in short-term memory without building strong long-term memory. Elaborative rehearsal, meaningful association, and repeated motor practice create richer traces, as when a touch typist learns a whole movement sequence rather than separate letters.

## Retrieval

![[attachments/memory_003.png|420]]

*Hippocampus memory diagram*

Retrieval depends on the kinds of attributes stored with a memory. Tip-of-the-tongue experiences show that people may remember a first letter or syllable count without retrieving the full word. Memories can include time, frequency, spatial position, visual features, or auditory features, and some attributes fade faster than others. Endel Tulving distinguished retrieval processes that involve different kinds of remembered experience.

## Relearning

Relearning ([Wikipedia](https://en.wikipedia.org/wiki/Recall_%28memory%29)) measures retention by comparing original learning with later learning of the same material. If a person first needs 10 trials and later needs 5 trials to reach the same level, the savings score is 50 percent. Relearning can reveal retained memory even when ordinary recall seems poor, though some tasks make the measure more or less sensitive.

## Forgetting

Forgetting is not simply a passive fading of memories over time. Memory traces may change, but disuse alone does not explain all forgetting. Different kinds of information disappear at different rates, and failure to retrieve a memory can depend on context, cues, interference, or changes in how the memory is stored.

## Interference

Interference explains forgetting through competition between memories. Retroactive inhibition occurs when new learning disrupts old memories, while proactive inhibition occurs when old memories disrupt new learning. List-learning experiments show that people who learn two lists recall less than people who learn only one, especially when the lists are similar.

## Amnesia

Amnesia can follow damage to brain regions such as the hippocampus. Some people cannot form new long-term memories, and some also lose earlier memories, called retrograde amnesia. Short-term memory may remain intact, and amnesic people can sometimes learn skills or habits without remembering the learning episode itself.

## Aging

Aging affects some memory types more than others. Episodic memory and associative memory often decline, especially remembering names with faces or recalling where an event memory came from. Marcia K. Johnson and Larry L. Jacoby showed that older adults may remember the general meaning of an action but have more trouble with specific details and origin memory.

## Key Events & Developments

- Late 20th-century memory research separated short-term storage, executive attention, working memory, retrieval, relearning, interference, amnesia, and aging effects.
- Five-day spaced practice examples showed why distributed study can beat one-day massed study for later recall.

## Key People

- Alan Baddeley ([Wikipedia](https://en.wikipedia.org/wiki/Alan_Baddeley)): Developed the working-memory model used to explain short-term storage and executive attention.
- Endel Tulving ([Wikipedia](https://en.wikipedia.org/wiki/Endel_Tulving)): Contributed distinctions in memory and retrieval processes.
- Marcia K. Johnson ([Wikipedia](https://en.wikipedia.org/wiki/Marcia_K._Johnson)) and Larry L. Jacoby ([Wikipedia](https://en.wikipedia.org/wiki/Larry_L._Jacoby)): Studied aging, detail memory, and source memory.

## Interesting Facts

- A tip-of-the-tongue state can preserve the first letter or syllable count without the full word.
- Relearning ([Wikipedia](https://en.wikipedia.org/wiki/Recall_%28memory%29)) can show memory savings even when direct recall seems weak.
- Amnesic learning may preserve some skills even when new personal events cannot be remembered.
